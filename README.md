Исследование ценообразования на вине итальянского маркетплейса Tannico.

|---|---|

### 3. Денежно-кредитная политика и макроэкономика России: репликация Uhlig (2005)
`time_series_monetary_policy.pdf`

Байесовский структурный VAR со знаковыми ограничениями на российских данных 2015–2025 — период инфляционного таргетирования.

| | |
|---|---|
| **Данные** | ВВП, ИПЦ, экспорт, резервы, госдолг, RUONIA · Росстат / ЦБ РФ |
| **Методы** | BSVAR, знаковые ограничения, IRF, FEVD · пакет VARsignR (R) |
| **Основа** | Uhlig H. (2005), *Journal of Monetary Economics* |

### 4. Санкции и российский экспорт: гравитационная модель на панельных данных
`panel_gravity_russian_exports.pdf`

Как изменилась ценовая чувствительность российского экспорта печатной продукции (товарная группа 49) после 2022 года и отличается ли этот сдвиг для стран-санкционеров.

| | |
|---|---|
| **Данные** | 997 наблюдений, 164 страны, 2017–2025 · BACI HS17 и UN Comtrade (зеркальная статистика) |
| **Методы** | Pooled OLS, FE, RE; тесты Вальда, Бройша–Пагана, Хаусмана, Мундлака; кластеризованные ошибки; динамическая панель (GMM Ареллано–Бонда и Бланделла–Бонда) |
| **Результат** | Ценовая чувствительность экспорта после 2022 г. выросла, но значимых отличий для стран-санкционеров не найдено: сдвиг носит общий характер |
